# G3

Долгоживущая семантическая база о том, как ходит цена вокруг RIZ.

Под ней лежит готовое поле: около двадцати лет минутной ленты ES, NQ и YM, с
материализованными Blue/2X ризами на каждом целом таймфрейме от 1 до 1440 минут.
Поле — это карта, а не эдж. T0 говорит, где и когда смотреть; он не говорит,
покупать или продавать.

Работа — находить повторяемые перекосы в поведении цены вокруг этих зон и
доводить выжившие до торговых сетапов. В конце база кормит робота, который
торгует только одобренное трейдером.

## Вход

Агенты заходят через [`AGENTS.md`](AGENTS.md): мандат, правила мышления и
преемственность. Затем — рыночная история и учебные случаи в
[`reference/SCENE.md`](reference/SCENE.md), точные термины по надобности в
[`GLOSSARY.md`](GLOSSARY.md), состояние поля и команды — в
[`WORKBENCH.md`](WORKBENCH.md).
Накопленное — [`base/`](base/README.md), торгуемое — [`setups/`](setups/README.md).

```powershell
pip install -e .
python -B -m g3riz.cli status
```

## Что где

| Путь | Что там |
|---|---|
| `AGENTS.md` | Вход: мандат, как думать, как сохраняется преемственность |
| `WORKBENCH.md` | Изменяемое состояние: поле, команды, чем читать, где что лежит |
| `GLOSSARY.md` | Словарь: живое слово, канонический термин, поле поля |
| `base/` | База: линии знания, живые и закрытые |
| `setups/` | Торгуемое: собранные сетапы и решения трейдера |
| `src/g3riz/` | Чтение поля, Film, треки и линзы. Считает, но выводов не выдаёт |
| `tests/` | Страховка общего слоя, а не покрытие исследований |
| `reference/` | Pine-исходник от трейдера, прибитый контрольной суммой, [`SCENE.md`](reference/SCENE.md) — рыночная история и учебные случаи, [`ENTRY_CHECK.md`](reference/ENTRY_CHECK.md) — измерение самого входа |

## Локальные байты

Большие данные в git не едут:

```text
data/raw/                 исходное вложение
data/market/{ES,NQ,YM}/   канонические минутные ленты
data/field/<инструмент>/  готовое поле ризов
data/research/NNN/        тяжёлый вывод по записи
work/NNN/                 разовый код и логи
```

Свежий клон понимает проект и видит записи базы, хеши источников и Pine. Для
настоящей работы нужно подключить локальные `data/market` и `data/field` и
запустить `python -B -m g3riz.cli status`. Отсутствие данных никогда не
считается пустым рынком и не является поводом что-то пересобирать.

[`SOURCE_DATA.json`](SOURCE_DATA.json) — хеши источников, преобразования, число
строк и нерешённые вопросы происхождения.

## Машина, которая построила поле

Поле заморожено, и сборщик из рабочего дерева убран: исследователю он не нужен, а
на глаза лезет. Он лежит в истории git — в коммите `dd278b6` и на ветке
`snapshot/pre-restructure`. Вернуть его можно только после явного решения
трейдера: на новое семантическое поколение или на восстановление после
подтверждённой потери данных.
