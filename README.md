# G3 RIZ research field

G3 stores the ES, NQ, and YM one-minute market tapes once and materializes the
RIZ passports and sparse lifecycle facts once for every native timeframe from
1 through 1440 minutes. Research code reads these persisted facts and slices
the shared minute tape by integer position; it does not replay the RIZ machine
or open one file per film.

The authoritative semantic and acceptance contract is
[`G3_RIZ_FIELD_IMPLEMENTATION_BRIEF.md`](G3_RIZ_FIELD_IMPLEMENTATION_BRIEF.md).
Source-feed origin, license, timezone metadata, and continuous-roll construction
are undocumented by the source. The build preserves that uncertainty.

## Repository data layout

Generated bytes are deliberately Git-ignored:

```text
data/raw/                 attached immutable source CSVs
data/market/{ES,NQ,YM}/   canonical NumPy market spines and manifests
data/field/<instrument>/  resumable per-timeframe facts and optional consolidated reads
```

Tracked code, schemas, tests, manifests, and compact benchmark reports are the
reproducible description of those local bytes.

## Build outline

```powershell
python -m g3riz.cli ingest --instrument ES --source data/raw/ES_1min.csv
python -m g3riz.cli ingest --instrument NQ --source data/raw/NQ_1min.csv
python -m g3riz.cli ingest --instrument YM --source data/raw/YM_1min.csv
python -m g3riz.cli build --instrument NQ --tfs 1-1440
```

The same build command applies to ES and YM. The scheduler derives a safe worker
policy from live RAM, measured cell working sets, CPU capacity, and free disk.
Completed timeframe partitions are content-bound and reused on resume.

## Cold-agent entry and recovery

From the repository root, the persisted manifests—not a chat transcript—state
what exists:

```powershell
$env:PYTHONPATH = "$PWD\src"
python -m g3riz.cli status
```

`complete_tfs` are atomically published and are reused by the default `build`
command. `missing_tfs` are the exact resume set. `.tf_...` directories listed
under `temporary_directories` are interrupted scratch outputs and never count
as complete. Resume safely with, for example:

```powershell
python -m g3riz.cli build --instrument NQ --tfs 1-1440
```

Repository-wide reads use all completed columnar cells as one Arrow dataset, so
they do not require a second multi-gigabyte copy. `consolidate` is an optional
explicit optimization only when free disk and measurement justify it. A basic
field-only query is:

```powershell
python -m g3riz.cli query --instrument NQ --tf 10 --limit 5
```

For Python research, use `g3riz.query.Field.passports`, `.events`, and
`.minute_windows`. The returned Arrow tables and NumPy arrays are factual field
views; research classifications belong in disposable downstream code.
