# G3

Пространство совместного исследования рынка и поиска торговых сетапов.
Здесь человек и AI замечают интересные сцены, превращают догадки в проверяемые
действия и постепенно собирают библиотеку результатов, на которые можно
опереться. Любопытство, честное несогласие и готовность учиться помогают этой работе.

Основная область исследования — цена вокруг RIZ. Под ней лежит готовое поле:
около двадцати лет минутной ленты ES, NQ и YM, с материализованными Blue/2X
ризами на каждом целом таймфрейме от 1 до 1440 минут. Поле даёт места и часы
наблюдения. Торговая ценность конкретного действия устанавливается отдельно.

Текущая цель — разные кандидаты с проверенным историческим расчётом на
существующей истории. В библиотеке остаются догадки, удачные и неудачные
версии, их объяснения и расчёты. Будущий исполнитель сможет использовать
только то, на что отдельно получено разрешение трейдера.

## Начать здесь

[`AGENTS.md`](AGENTS.md) — общий вход: цель, самостоятельность, границы и
преемственность. [`CLAUDE.md`](CLAUDE.md) направляет туда же.

Дальше выбери маршрут по своей задаче:

| Задача | Куда идти |

| Впервые познакомиться с RIZ | Основная история и упражнение в [`reference/SCENE.md`](reference/SCENE.md); точные слова — в [`GLOSSARY.md`](GLOSSARY.md) |
| Начать или продолжить поиск сетапа | [`setups/README.md`](setups/README.md), карточка и её сохранённый расчёт |
| Найти, что уже исследовали | Тематические входы и поиск в [`base/README.md`](base/README.md) |
| Перейти от сцены к эксперименту | [`reference/CONTRACT.md`](reference/CONTRACT.md), разделы II и IV; объяснить действие — раздел III |
| Прочитать данные или изменить общий инструмент | [`reference/README.md`](reference/README.md), [`src/g3riz/README.md`](src/g3riz/README.md) и команды в станке |

Подробности можно открывать по мере работы. При знакомстве с RIZ проверяй
понимание на конкретной сцене с закрытым будущим. История испытаний самого
входа — в [`reference/ENTRY_CHECK.md`](reference/ENTRY_CHECK.md); это материал
для улучшения среды, а не оценка ценности читателя.

Текущий указатель на работу один — [`WORKBENCH.md`](WORKBENCH.md#что-сейчас-на-столе).
Точные версии, числа, ограничения и открытые решения живут у владельца —
в карточке. Например, сохранённая S-07 использует минутную ленту и время сессии
без поля RIZ: связь каждого результата с основным предметом называется явно.
Наличие карточки не означает подтверждённого преимущества или разрешения торговать.

## Как связано дерево

| Путь | Его роль |
|---|---|
| `AGENTS.md`, `CLAUDE.md` | Общие условия работы и вход для агента |
| `WORKBENCH.md` | Текущая работа, доступность среды, команды и размещение результатов |
| `GLOSSARY.md` | Точные значения слов и соответствующие поля данных |
| `reference/` | Учебная сцена, переход к эксперименту, проверка входа, Pine-источник |
| `base/` | Самостоятельные вопросы и ограниченные выводы о рынке; одна линия знания — одна карточка |
| `setups/` | Действия: от догадки до исполнения и решения; расчёт лежит рядом с карточкой |
| `src/g3riz/` | Общие инструменты чтения поля, фильмов, треков и линз |
| `tests/` | Проверки общего инструмента; предметные проверки — рядом с кандидатами |
| `SOURCE_DATA.json` | Происхождение источников, преобразования, хеши и известные неопределённости |
| `PROJECT_STATE.json` | Датированный снимок готовности поля; фактическую доступность показывает `status` |
| `RIZ_RESEARCH_VERDICT.md` | Датированный разбор 2026-09-06; историческое свидетельство, актуальные выводы — в карточках |
| `pyproject.toml`, `.github/` | Среда общего слоя и его автоматические проверки |

Смысловая связь: **наблюдаемая сцена → вопрос или догадка → проверка →
ограниченный вывод либо кандидат → следующее решение**. Общий факт сохраняется
в `base/`, цельное торговое действие — в `setups/`. Кандидат ссылается на нужные
факты; непроверенная догадка может начаться без готовых опор.

## Работа с локальной машины

Из корня репозитория, Python 3.11 или новее:

```powershell
pip install -e ".[dev]"
python -B -m g3riz.cli status
```

Это среда общего слоя. Зависимости и команды конкретного кандидата указаны
в его `S-NN/README.md`; проверки и пример чтения — в [`WORKBENCH.md`](WORKBENCH.md).

Большие данные и временная работа остаются локально:

```text
data/raw/                 исходное вложение
data/market/{ES,NQ,YM}/   канонические минутные ленты
data/field/<инструмент>/  готовое поле RIZ
data/research/NNN/        тяжёлые результаты исследования
work/NNN/                 черновые прогоны и логи
```

Свежий клон содержит документы, код, малые результаты, хеши источников и Pine.
Для расчёта подключи существующие `data/market` и, если нужен RIZ, `data/field`.
Как проверить подключение — в [станке](WORKBENCH.md#локальная-среда).
Отсутствие данных означает недоступность расчёта, а не пустой рынок.
Код и параметры, необходимые для повторения значимого результата, сохраняются
в git рядом с карточкой; `work/` служит временной работой.

Поле заморожено. Его сборщик сохранён в истории git — коммит `dd278b6`, ветка
`snapshot/pre-restructure`. Возврат и пересборка требуют отдельного решения
трейдера на новое семантическое поколение или восстановление после
подтверждённой потери данных. Недоступность массива пересборку не разрешает.

Эта история уже использовалась в поиске. На ней можно продолжать исследование
и исторические проверки; независимое подтверждение требует отдельно
установленной независимости данных и заранее определённого правила.
