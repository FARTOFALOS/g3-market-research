# Повторение S-07

[Карточка](../S-07-drayf-pervyh-minut-sessii.md): дрейф первых минут сессии,
сторона по предрыночному положению цены. Поле RIZ не требуется — нужны только
минутные массивы `data/market/<ins>/` и календарь из S-04.

Из корня `g3-market-research`. Среда как у S-05: Python 3.14.4,
[зависимости](../S-05/requirements.txt). Локально — `data/tmp/s04-venv`.

```powershell
python -B setups/S-07/run.py
python -B setups/S-07/verify.py
python -B setups/S-07/field.py across
python -B setups/S-07/manage.py
python -B setups/S-07/scenes.py
python -B setups/S-07/freeze.py
```

`run.py` считает все 675 конфигураций (3 инструмента × минуты решения 0–14 ×
горизонты 30/60/120 × стопы 0/2/4/6/10 свечей) и пишет `summary_v1.csv` и
`data/research/S-07/trades_v1.parquet` со всеми сделками. `verify.py` даёт
устойчивость, стоимость годового выбора среди всех конфигураций и физическое
обрезание ленты. `field.py` — отвергнутая проверка живого RIZ как фильтра;
для неё нужны копии паспортов `data/research/S-06/<ins>_objects.parquet`
(готовятся `python -B setups/S-06/run.py prepare`).

| Что | Где |
|---|---|
| Все конфигурации и итоги | `summary_v1.csv` |
| Устойчивость, выбор, префикс | `verification_v1.json` |
| Расщепление по полю RIZ | `field_split_v2.csv`, `field_across_v2.csv` |
| Все сделки | `data/research/S-07/trades_v1.parquet` |
| Ведение, диагностика провала, размер | `management_v3.csv`, `diagnostics_v3.csv`, `sizing_v3.csv` |
| Сцены с закрытым будущим | `scenes.png`, `scenes.json` |
| Прогон v1 на минутах вне корпуса (TradingView) | `oos_tradingview_v1.json` |
| Заморозка версии v1: хеши кода, входов, среды | `FROZEN_v1.json` |
| Перенос правила на TradingView | `S07_opening_drift.pine` |
| Хеши кода | `run_hashes_v1.json`, `FROZEN_v1.json` |

Календарь — XNYS 4.13.2, America/New_York, исторические сокращённые сессии.
Единица «свеча» — медиана истинного диапазона последних 30 закрытых минут.
День без полного префикса или без минуты входа исключается, а не считается нулём.
Живого исполнения здесь нет; расход фиксированный, проскальзывание не моделируется.

Замороженная версия v1: NQ, решение на 3-й минуте сессии, вход по open 4-й,
лимит 16 свечей, выход на 15-й минуте при минусе, иначе 120 минут, без
безубытка и трейлинга. Менять параметры внутри v1 нельзя — новая проверка
получает новый номер версии и свою строку в истории выбора карточки.
