# Повтор S-08 v1

Правило и результат: [карточка](../S-08-otmena-vneshnego-otkrytiya.md).
Критика прежнего исследования: [AUDIT.md](AUDIT.md). Правило не использует RIZ
или Volume; один NQ, не больше одной позиции за основную сессию.

Из корня репозитория:

```powershell
python -B setups/S-08/check.py
python -B setups/S-08/run.py run
python -B setups/S-08/validate.py
python -B setups/S-08/present.py
```

`observe` вместо `run` печатает три выбранных префикса без их исходов.
Проверка исполнения не выбирает параметры. `validate.py` содержит отдельно
названные диагностики, выбранные после первого итога; они не меняют v1.

Входы: пять массивов `data/market/NQ/{close_ts_utc_ns,open,high,low,close}.npy`,
их manifest и `SOURCE_DATA.json`; календарь `setups/S-04/calendar.parquet`
(XNYS 4.13.2, ранние закрытия включены). Все OHLC расчёта ограничены
2025-11-01 UTC; предыдущий календарный день никогда не заменяется более старым
«удобным» днём при пропуске. Проверка SHA-256 подтверждает байты, не
независимость истории и не происхождение исходного фида.

Версии среды и хеши: `result.json`, `validation.json`, `provenance.json`.
Таблицы полного знаменателя и всех исполнений —
`data/research/S-08/recognition.parquet`, `trades.parquet`; генерируются заново.
`daily.csv`, `summary.csv`, `yearly.csv`, исходные три сцены и малые проверки
хранятся рядом с кодом, переживают очистку тяжёлых результатов.
Дневной NaN означает неизвестные условия, а не отсутствие сделки.

Для аудита 060: `python -B setups/S-08/audit_checks.py` дополнительно требует
**имеющийся локальный** `work/060/visits.pkl` и оригинальные скрипты 060 с
хешами из `audit_checks.json`. Ничего в старых массивах он не меняет.
Текстовые копии скриптов — в `audit_evidence/`; старые тяжёлые массивы не
объявляются частью свежего клона. Количественный аудит не является повтором
всех старых денег; контрпримеры перечислены отдельно.

Расходы $15/$30 — сценарии. Цена пункта и шага сверена с
[CME](https://www.cmegroup.com/markets/equities/nasdaq/e-mini-nasdaq-100.contractSpecs.html).
Временной выход точен по часам; для барьерного выхода число минутных свечей
задаёт верхнюю границу длительности, внутриминутная доля неизвестна.
