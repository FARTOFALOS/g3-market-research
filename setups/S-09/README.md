# Повтор S-09 v1

Правило и результат: [карточка](../S-09-dve-dveri-dnya.md). Правило не использует
поле RIZ и объём. NQ основной; ES и YM считаются тем же кодом без изменения
параметров.

Из корня репозитория:

```powershell
python -B setups/S-09/run.py checks
```

`run` вместо `checks` считает только деньги, без проверки префикса и интервала.
Один файл, без зависимостей от `work/`. Время счёта — около минуты.

## Входы

Пять массивов `data/market/{NQ,ES,YM}/{close_ts_utc_ns,open,high,low,close}.npy`
и календарь `setups/S-04/calendar.parquet` (XNYS 4.13.2, ранние закрытия
включены). SHA-256 входов и кода записываются в `result.json` при каждом счёте.
Проверка хешей подтверждает байты, но не независимость истории и не
происхождение исходного фида: метаданные часового пояса и способ склейки
фьючерсов по `SOURCE_DATA.json` неизвестны.

## Что получается

- `trades.csv` — все сделки: дверь, время, сторона, вход, выход, исход,
  длительность, единица свечи, валовое и чистое.
- `daily.csv` — дневной итог по календарю поиска; дни без сигнала отсутствуют,
  нулём не заменяются.
- `result.json` — сводки по дверям, годам, расходу $30, ES и YM; проверка
  префикса; интервал месячного блочного пересэмплирования; итог без пяти
  лучших дней и без 2022 года; хеши.
- `clock.csv` — просмотренное семейство: результат каждой из 389 минут решения
  основной сессии при том же действии и удержании 120 минут. Проигравшие
  варианты сохранены, а не выброшены.

## Оговорки к числам

Расход $15 за оборот на NQ и $30 на ES — допущения ($5 комиссия плюс 0,5 пункта
проскальзывания), а не измеренные брокерские исполнения. Цена пункта и шага
сверена с [CME](https://www.cmegroup.com/markets/equities/nasdaq/e-mini-nasdaq-100.contractSpecs.html).
Вход по open следующей минуты требует доступности этой цены; нулевая задержка
не гарантируется. Предел исполняется по своей цене, а при разрыве через него —
по open минуты, то есть хуже предела. Внутриминутный порядок событий при
одновременном достижении предела и конца окна разрешён в пользу предела.

Кусок 2025-11-01 … 2026-05-04 при поиске не открывался, но чистым общим holdout
не является: прежние линии репозитория описывали более поздние данные, и
независимость этого куска от всей истории доступа не установлена.
