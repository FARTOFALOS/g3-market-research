# Повтор S-20 v1

Правило, история выбора и ответ —
[`S-20`](../S-20-pervyy-retest-utrennego-ekstremuma.md). Рыночный вопрос и
адресные X-ray сцены — [`104`](../../base/104-pervoe-ispytanie-utrennego-ekstremuma.md).
Нужны исходные `data/market/NQ` и `data/market/ES` с идентичностями из
`SOURCE_DATA.json`; код читает их, не пишет туда и не читает Volume.

Из корня репозитория, Python ≥3.11:

```powershell
pip install -r setups/S-20/requirements.txt
python -B base/104/xray_scenes.py
python -B setups/S-20/run.py
python -B setups/S-20/replicate_es.py
python -B setups/S-20/audit.py
```

Первый код создаёт только локальные картинки `work/104/scenes/` для пяти
названных дней. Денежные прогоны сохраняют полные дневные потоки
`daily.csv`/`daily_ES.csv` и малые `result.json`/`result_ES.json`.
`audit.json` сверяет все известные исполнения с OHLC. В результатах сохранены
`corpus_id`, хеш кода правила, версии вычислительной среды, знаменатели и
причины неизвестности. Локальный `work/103/deps` используется лишь как
запасной путь к уже установленному календарю, если пакет отсутствует в Python.

NQ: стоимость 1 пункт = $20 за оборот. ES-репликация: те же $20 = 0,4 пункта
при множителе $50/пункт. Это модель расходов, а не котировка брокера.
Неполные дни имеют `net=null`; известные нулевые дни входят в знаменатель.
Результат выбран на исторически раскрытом архиве и не является независимой
temporal проверкой или разрешением живой торговли.
