# Archive

Nothing here is deleted, and nothing here is authoritative. These are documents
that governed building the field. The field is built and frozen, so they no
longer describe live work — but they record how it was built and why, and an
auditor may need them.

| File | What it was | Why it moved |
|---|---|---|
| `G3_RIZ_FIELD_IMPLEMENTATION_BRIEF.md` | The contract the materialization was built against, including the final semantic-freeze amendment. | 28 KB of build instructions for a field that is complete. A cold agent reading it starts thinking about rebuilding, which is exactly the wrong first move. The semantics it froze now live in `GLOSSARY.md` and `RIZ.md`. |

If a genuine rebuild is ever authorized, this brief is the authority for it, not
the current documentation.
