# FREEZE 089 — определения descriptive bridge «immediate continuation law внутри joint-фазы»

089 — один описательный замер (не hazard-модель, не сетап). Замораживаются
определения эстиманда и state-осей, взятые по ссылке из установленной линии; ничто
не подгонялось под исход. `Volume` не загружался.

## 1. Объект и популяция

- Объект и живая наружная сцена — дословно [`FREEZE_088`](../088/FREEZE_088.md) §1–2:
  object-scene одного `riz_id`, наружу от `b`, фронты `M/MB`, терминалы
  `contact_b`/`retreat_in`/`gap`/`archive`, горизонта нет — сцена до `end_pos`.
- Единица независимого свидетельства — физический акт `(t0_spine_pos, side)`,
  дедуп эпизода `sort_values('life').groupby(['t0_spine_pos','side']).last()`
  (как 088). Популяция — Film-1 080/081 без отбора по судьбе.
- Территория — **NQ discovery** (T0 2006-01-05 … 2018-12-24). ES/YM и evaluation
  не открывались.

## 2. Событие грамматики и эстиманд CONT (заморожено до результата)

- Квалифицирующее событие = фронт-апдейт `newM ∨ newMB`, детекция бит-идентична
  `fullfilm.annotate` (`M,MB` стартуют с бара 0; `newM⇔Wo>M`, `newMB⇔Bo>MB`).
- `CONT(q)=1` ⇔ за живым фронт-событием q следует хотя бы одно ещё квалифицирующее
  фронт-событие **до физического терминала сцены**; иначе `0`. У последнего события
  фильма `CONT=0`. **Горизонта нет.**
- Что CONT **не** есть (не подменять): остаток числа событий; остаток минут;
  eventual contact_b; short/long фильм; P&L; WOECB′.

## 3. State-координаты (заморожены по ссылке, не изобретены)

На баре события `j = t0 + k`, `sgn = +1` для north, `−1` для south:

- `dpos(q) = sgn·(close[j] − exit_boundary)` — знаковое расстояние закрытия
  курсора до собственной границы b, наружу-положительное. Это `d_close` линии
  080/081.
- `psig(q) = mean_{t=t0..j}(high[t] − low[t])` — префиксный кумулятивный средний
  размах бара. Это дословно оператор `_sig` из
  [`base/081/sigma_control.py`](../081/sigma_control.py) (`prefix_sigma`),
  вычисленный на баре события. Эволюционирует с q; ранний фикс-курсор σ из 076 в
  событийное время **не** переносился.
- `nz(q) = dpos/psig` — детерминированная комбинация двух замороженных величин.

Зрелость (порядковый номер события) — только диагностическая ось состава, в feature
не возведена.

## 4. Знаменатель и веса (объявлено до результата)

- Primary — event-risk: одна строка на живой фронт-событийный курсор.
- Повторные курсоры одного фильма независимым свидетельством не считаются:
  неопределённость кластеризуется на физическом акте (block bootstrap ресэмплом
  актов, 300 повторов, seed 89); опора в актах публикуется по каждой части
  поверхности.
- Scene-balanced sensitivity объявлена заранее: курсор весит `1/n_events(film)`,
  чтобы фильм на 100 событий не получал 100× влияния фильма на 1 событие. Между
  двумя весами не выбирали по красоте — публикуются оба.

## 5. Поверхность (без оптимизации)

Границы бинов — квантильные рёбра маргиналов состояния (только распределение
состояния, не CONT): децили для 1-D, 6×6 квантильная сетка для 2-D. Порогов не
искали, монотонности не предполагали, локальные бугры в кандидаты не возводили.
