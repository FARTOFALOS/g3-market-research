## 1. Вилка в `q_event`

- `c = close(q_event)`, `b = exit_boundary`, `d = |c − b| > 0`.
- `M` — бегущий внешний экстремум к закрытию `q_event`: north — максимум high,
  south — минимум low по `T0 … q_event`. Бар `q_event` не обновляет экстремум, и
  `M` от него не меняется.
- Уровень отмены `a` — первый тик за `M` наружу: north `M + tick`, south
  `M − tick`. Отсюда `s = |a − c| = |M − c| + tick`.
- Тик: NQ и ES 0,25; YM 1,0.
- Безубыточная вероятность фильма: `p0 = s / (d + s)`.

## 2. Автомат после `q_event`

Бары `j = q_event + 1, …` без горизонта. На каждом баре по порядку:

1. бара нет → `archive_edge`;
2. промежуток ленты перед баром → `lost_observability`;
3. бар накрыл `b` и `a` → `same_bar`;
4. накрыл только `b` → `win` (`Y = 1`);
5. накрыл только `a` → `cancel` (`Y = 0`);
6. бар целиком за `b` или целиком за `a` без касания → `gap_transition`, сторона
   (через `b` или через `a`) записывается;
7. иначе следующий бар.

Касание: `low ≤ уровень ≤ high`, одно для обоих уровней. Каждый терминал
окончательный. Бар, перепрыгнувший `a`, — новый экстремум на языке X-Ray, но
здесь он `gap_transition` со стороной «через `a`», как в 084.

## 3. Величины и вердикт

- **По фильму:**
  - `win` / `cancel`: `x = Y − p0`, `g = (d + s)·x`, то есть `+d` или `−s`;
  - `same_bar`, `lost_observability`, `archive_edge`: `x ∈ [−p0; 1 − p0]`,
    `g ∈ [−s; +d]`;
  - `gap_transition`: `x = 0`, `g = 0`; остаётся в `N`, публикуется отдельно со
    стороной.
- **Средние:** `X = mean x` (нормализованный структурный edge), `G = mean g`
  (валовое ожидание в пунктах). Вес 1 на `riz_id`; идентифицированные интервалы
  `[X_lo; X_hi]`, `[G_lo; G_hi]`.
- **Статистика:** блочный бутстрэп по `t0_day` (UTC), блоки 1 / 5 / 20 подряд
  идущих дней, 2 000 реплик на длину, seed 20260916 + длина блока. Для каждой
  длины — [2,5 % нижней; 97,5 % верхней]; публикуется самое широкое.
- **Класс по `X`:**
  - всё множество выше нуля — положительный структурный edge вилки к `b`;
  - ниже нуля — положительна обратная сторона этой же бинарной ставки
    (continuation-стратегию это не доказывает);
  - иначе unresolved. Причина — идентификация, если `[X_lo; X_hi]` содержит 0,
    иначе точность.
- **Порог расходов, не net:** круг 057 — NQ 1,00, ES 1,00, YM 4,00 пункта.
  Публикуются множество `G` рядом с порогом и средний порог в единицах `X`:
  `mean(cost / (d + s))`.
- **Чувствительность** (только для общего шага): вес 1 на путь
  `(инструмент, T0, сторона)`.

## 5. Бюджет разрешения

Строится без исходов вилки: из геометрии `(d, s)` и уже известной кластерности 084.

- При отсутствии edge `Var(x) = p0(1 − p0)`, поэтому
  `SE_iid(X) = sqrt(Σ p0(1 − p0)) / N` и `SE_iid(G) = sqrt(Σ d·s) / N`.
- **Кластерность** берётся из зеркальной гонки 084 того же инструмента и
  семейства периода (per-film `1{own} − 1{mirror}`):
  - `deff` = самая широкая дисперсия блочного бутстрэпа / iid-дисперсия;
  - `ρ = (deff − 1) / (K − 1)`, где `K = Σ m_day² / N`;
  - для подмножества `deff_sub = 1 + ρ (K_sub − 1)`.
- **Сдвиг идентификации — прокси:** доля неизвестного порядка (`same_bar` +
  `lost` + `edge`) у `close_break` в 084 по территории.
- **Минимально различимая величина, два уровня:** порог на 95 % (`z = 1,96`) и
  при мощности 80 % (`z = 2,80`):
  - плюс: `ū·mean(p0) + z·SE`;
  - минус: `ū·(1 − mean(p0)) + z·SE`;
  - для `G` — те же формулы через `mean(s)` и `mean(d)`.
- **Считается для:** NQ development, NQ evaluation, поиска, отложенного куска,
  каждой клетки карты, ES и YM evaluation.
- Бюджет не ворота: он заранее говорит, какой размер прибор способен
  различить.

## 6. Карта на NQ поиске

**Координаты в `q_event`:**
- `u = d / σ`, где `σ = mean(high − low)` по `T0 … q_event` (085);
- `k = q_event − T0` — возраст в барах;
- `ttc` — минуты от закрытия `q_event` до ближайшего официального закрытия
  XNYS не раньше него (`setups/S-04/calendar.parquet`);
- `r = s / d`.

**Клетки — фиксированная сетка, кластеризации нет:**
- **алгоритм:** деление каждой из четырёх координат по её медиане, `≤ медианы`
  — low, `> медианы` — high; `K = 16` клеток `2⁴`. Seed нет, подгонки к исходу нет;
- **территория расчёта точек деления:** фильмы `close_break` NQ поиска
  (T0 2020-01-01 … 2025-10-24) с определённым `ttc`;
- точки деления считаются без исходов и записываются с хешем в
  `work/086/cells086.json` до первого исхода вилки;
- фильмы без определённого `ttc` не входят в карту, число публикуется;
- **правило малой клетки:** флаг может получить только клетка, в которой на
  поиске не меньше 50 разных дней T0. Меньшая клетка публикуется, но не
  отмечается и на отложенный кусок не переносится;
- других делений, координат, слияний и порогов нет.

**По клетке:** `N`, дни, доля `q_event` в окне 03:00 ET → закрытие XNYS,
`mean(p0)`, `X` и `G` (интервал и множество), класс, порог расходов, бюджет.

**Отмеченная клетка** — множество `X` исключает ноль при соблюдении правила
малой клетки; знак записывается. Если edge нет нигде, ложных отметок ожидается
около 0,8 из 16.

**Заморозка выбора.** После карты и до любого исхода отложенного куска
отмеченные клетки и их знаки записываются в `work/086/selected086.json` с хешем.
Выбранная область — группа отмеченных клеток одного знака; клетки разных знаков
образуют разные области.

## 7. Отложенный кусок — один раз

- Точки деления и выбранные области применяются без изменений. Знак на
  отложенном куске не выбирается никогда.
- **Основное — сырые `X` и `G`**, без переворота знака:
  - по всей популяции отложенного куска;
  - по каждой выбранной области (её клетки вместе).
- **Область подтверждена**, если сырое множество `X` на отложенном куске лежит
  по ту же сторону нуля, что и знак, замороженный на поиске. Иначе «не
  подтверждено», и бюджет называет различимый размер.
- Если выбранных областей нет, кусок сообщает только общие сырые `X` и `G`;
  область не установлена.
- **Вторично:** знаково выровненный `X` по всем выбранным клеткам — среднее
  `sign_поиска · x` — и каждая выбранная клетка отдельно. Знаки только из
  `selected086.json`.

## 8. Чего проход не устанавливает

Торгового edge (вход по следующему open, fill, проскальзывание, буфер стопа);
прибыльности continuation-стратегии; механизма; специфичности RIZ; причинной
роли координат.
