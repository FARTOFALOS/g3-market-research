## Объявленная экспозиция

Проход evaluation по конструкции **v1** был выполнен до получения указания о
торговом окне. Его результаты лежат в `work/081a/evaluation.json` и здесь

не видена, нельзя. Статус прежний: later-epoch evaluation with known prior

## Торговое окно

**03:00 America/New_York → официальное закрытие XNYS**, исторические сокращённые
дни. Календарь взят готовым: `setups/S-04/calendar.parquet`,
`exchange_calendars` 4.13.2, конвенция «NYSE cash close, including historical
early closes». Окно не подбиралось.

Префикс читается от настоящего T0, включая внеоконные бары. Минута вне окна
решением не является и попытку не расходует. Пригодность проверяется по бару
входа: сигнал, чей next open лежит за закрытием XNYS, отменяется; в дни, когда
XNYS закрыта, входов нет.

## Исполнение — заморожено один раз

Вход `open[q+1]`. TP — собственная exit boundary; **основная условная модель:
касание = исполнение**. Стоп — `k × gross` от цены входа; наблюдаемое касание
срабатывает; бар, открывшийся за стопом, исполняется по худшему open. Оба
барьера в одном баре — пара границ, среднее не берётся. Не закрытая барьерами
позиция закрывается по `close` последнего бара сессии (NY-close exit). Участок
внутри неизвестного промежутка оставляет исход `unknown`.

Обязательная консервативная чувствительность: TP засчитывается, только если
цена прошла границу не менее чем на тик; за пределы Film-1 ради fill не
читается; иначе `unconfirmed`.

## Политики

    A   age>=0, без порога, k выбран тем же критерием
    B   age>=2, d_close > 4c, k=2        (лучшая ячейка Семьи 1)
    B'  age>=2, d_close > 4c, k=2        (совпадает с B: те же age/D/k, что у C)
    C   age>=2, d_close > 4c, k=2, retraced_fraction >= 0,50

Критерий отбора прежний: `pessimistic_scenario_mean`, частота >= 2 %,
unknown <= 0,20. Из трёх объявленных θ выбран 0,50.

## Две вещи, записанные ДО evaluation

**1. Консервативная TP-чувствительность переворачивает знак C уже на discovery.**
`tp_unconfirmed_share` = 0,2256 — это доля **touch-wins (WIN ∪ AMBIG)**, не всех
исполнений; от всех исполнений это 0,1312.

| C, discovery | после расходов |
|---|---:|
| касание = исполнение (основная) | **+0,3665** |
| TP только при проходе на тик, неподтверждённые → `unconfirmed` | **−0,5098** |
| неподтверждённые вышли по стопу | −2,4563 |

Положительный торговый вердикт опираться только на оптимистичную конвенцию
касания не имеет права. Это sensitivity уже выбранной конструкции, а не ещё
один критерий отбора: C не переотбирался по её результату.

**2. Преимущество C над B' — не лучшая структура попаданий, а больший размер цели.**

| | B' | C | Δ |
|---|---:|---:|---:|
| win | +4,4441 | +5,5349 | **+1,0908** |

C **не возвращает к границе чаще**: частота попаданий не меняется. Он
превращает стопы в выходы по времени и берёт более крупную цель — медиана
`gross` 5,25 → 6,75 пункта, средний выигрыш 7,65 → 9,51. Основной источник
преимущества — размер сделки, то есть остаточная геометрия, а не
последовательность. Постановка §15 требует это назвать до evaluation.
