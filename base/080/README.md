# 080A — что здесь лежит и в каком порядке читать

Указатель, не выводы. Выводы живут в
[карточке 080](../080-film1-korpus-vosstanovim-granitsa-sertifikatsii-gap.md);
при любом расхождении права она.

## Порядок чтения

1. **[Карточка 080](../080-film1-korpus-vosstanovim-granitsa-sertifikatsii-gap.md)** —
   вопрос, два вердикта, все числа с таблицами, что установлено и чего не
   устанавливает.
2. **[FREEZE_080A](FREEZE_080A.md)** — определения и операторы, заданные до
   счёта: предикат контакта, таксономия промежутков, две сертификации, модель
   next-open reference, членство в риск-множестве, семантика первичности и
   цензуры. Чисел результата здесь нет намеренно.
3. **[results/hronologii_NQ.txt](results/hronologii_NQ.txt)** (и `_ES`, `_YM`) —
   тринадцать типов проверочных сцен на реальных объектах поля, каждая с полной
   хронологией `T0 известен → q доступны → reference executions → contact либо
   потеря достоверного наблюдения`. Это самая читаемая часть: видно, как
   выглядит одно решение и чем оно кончается. Первая сцена в каждом файле —
   решающая: состояние уже распознаваемо, reference open ещё исполним, а запаса
   до цели остаётся один-два тика.
4. **results/\*.json** — машинные выходы переписей, которыми проверяется каждое
   число карточки: `preflight.json` (население, лаг, цензура, кратности),
   `census_q.json` (решения и покрытие reference по ТФ, стороне и эпохам),
   `census_age.json` (покрытие как функция возраста Film-1 и разбивка по
   нативным ТФ-полосам), `census_unusable.json` (разложение непригодных q по
   причинам).

## Код

Тяжёлые артефакты (компактный индекс на 120,6 МБ) сюда не кладутся: они строятся
за минуту из замороженного поля. Каждый файл ниже — провенанс конкретного числа
карточки, поэтому ни один не выброшен как черновой.

| файл | что даёт |
|---|---|
| `tape.py` | таксономия промежутков ленты; трёхсторонняя решётка присутствия минут |
| `tape_gaps.py` | обзорная таблица промежутков: сколько, какого размера, когда |
| `contact.py` | быстрый ТОЧНЫЙ первый контакт; блочный пропуск по необходимому условию |
| `reference.py` | эталон полного прохода — медленный и очевидный, мера правоты быстрого |
| `equiv.py` | эквивалентность эталона и быстрого примитива, 10 ячеек трёх инструментов |
| `canon_check.py` | поэлементная сверка маски с каноническим `exit_boundary_touch_v1` |
| `index_build.py` | компактный per-RIZ индекс Film-1; три оси, две сертификации |
| `selftest.py` | инварианты индекса и совпадение с `first_exit_contact_v1` |
| `grid.py` | ленивый вид: `decision_prefix`, `execution_reference`, `continuation` |
| `qa_prefix.py` | информационная граница: prefix из полного и из обрезанного источника |
| `preflight.py` | перепись населения, лага, цензуры, кратностей |
| `census_q.py` | решения и покрытие reference на всех сертифицированных q |
| `census_age.py` | покрытие по возрасту Film-1; последний q перед контактом |
| `census_unusable.py` | разложение фильмов без пригодного q по причинам |
| `scenes.py` | хронологии из `results/` |

Повтор — в строке «повтор расчёта» карточки. Переменная `G3_080A_INDEX`
указывает на общий индекс, иначе он строится рядом с кодом.
