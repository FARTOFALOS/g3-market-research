# 082 — что здесь лежит и в каком порядке читать

Указатель, не выводы. Выводы живут в
[карточке 082](../082-prefiks-ne-neset-perenosimoy-informatsii-sverh-sigmy.md);
при любом расхождении права она.

## Порядок чтения

1. **[Карточка 082](../082-prefiks-ne-neset-perenosimoy-informatsii-sverh-sigmy.md)** —
   вопрос, четыре шага, перенос, предел различимости, что установлено и чего
   это не устанавливает.
2. **[DECLARE_082](DECLARE_082.md)** — что объявлено ДО первого взгляда на
   продолжение: четыре шага в порядке, устранение цензуры конструкцией вместо
   её моделирования, три чтения состояния, два чтения будущего, что опровергнет
   какой вывод, и шесть вопросов, на которые отвечено до счёта. Чисел
   результата здесь нет намеренно.
3. **[FINDINGS_SEMANTICS](FINDINGS_SEMANTICS.md)** — две проверки перед
   расчётом, обе давшие не тот ответ, которого ждала интуиция: дефект оси
   сертификации 080A (`nxt_any[t0]` вместо `nxt_any[t0+1]`) и живой Film-1 с
   закрытием по другую сторону границы. Читать до любого числа результата:
   первая определяет популяцию, вторая — что из неё исключено и почему.
4. **`work/082/scenes082_NQ_discovery.txt`** — одна ячейка сравнения и четыре
   реальных Film-1 со свечами: опора и контрпримеры В ОБЕ СТОРОНЫ, плюс фильм,
   у которого контакт пришёл в самом баре `q+1`. Самая читаемая часть: видно,
   что установленное — сдвиг доли, а не правило.
5. **`work/082/scenes_negative_NQ_discovery_a5.txt`** — восемь случаев гэпа
   через уровень со свечами.
6. **`work/082/*.json`** — машинные выходы, которыми проверяется каждое число
   карточки.

## Код

Тяжёлые артефакты сюда не кладутся: слой окна строится из замороженного поля
за секунды. Каждый файл — провенанс конкретного числа карточки.

| файл | что даёт |
|---|---|
| `semantics.py` | две проверки до счёта: пригодность q без ссылки на `F` независимым просмотром баров; знак `d_close` у живого Film-1 |
| `diagnose_mismatch.py` | причина расхождения префиксного критерия и `q <= F`; локализация дефекта и его размер |
| `scenes_negative.py` | свечи фильмов с `d_close <= 0`: гэп через уровень, а не ошибка предиката |
| `window.py` | слой 082: популяция среза по префиксу и полностью наблюдённое окно `at_risk(q,h)`; будущее меряется от `close[q]` |
| `contrast.py` | четыре шага в объявленном порядке; блочный бутстрэп по дням с блоками 1/5/20; support и разделение признака рядом с Δ |
| `crosstest.py` | решающий cross-test с утечкой второго признака и устойчивостью по nq ∈ {2,4,8} |
| `identify.py` | размер границы различимости: сколько остаточного пути лежит внутри бара контакта и различается ли это между группами |
| `observability.py` | квантили состава вместо медиан, доля пригодных по квартилям σ внутри страты, попытка проверки на часах без обусловливания |
| `holdout.py` | тот же замороженный cross-test без настройки на NQ evaluation, ES и YM |
| `scenes082.py` | ячейка сравнения и реальные Film-1: опора и контрпримеры в обе стороны |

Повтор — в строке «повтор расчёта» карточки. Слой `work/081a/paths/` должен
существовать: 082 берёт из него только список фильмов и их адреса, а все
чтения состояния и будущего считает заново от `close[q]`.

## Чего в 082 нет намеренно

Слоя исполнения (`open[q+1]`, `gross`, `mae_*`, семейство стопов), торгового
окна, правила входа, стопа и цели. Будущее меряется от опоры среза, а не от
цены входа: нормировать описание рынка величиной из entry-policy значит внести
в него чужую политику. Торговое действие из результата 082 не выводится.
