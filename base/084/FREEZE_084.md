## 2. Событие и `q_event`

Оператор — EVENT_XRAY_MAP §2, `close_break`, реализация `xray.py`.

- Наружу — от собственной границы `b`. `M` — бегущий внешний экстремум от `H[T0]`.
  Обновление — только `H > M` строго; ничья `H = M` не обновляет и `P` не двигает.
  `P` — первый бар, достигший текущего `M`.
- Пробой: бар без обновления и `C < L[P]` строго. Равенство не пробой. Бар с
  обновлением пробоем не бывает.
- Порядок на баре +k: k > 50 → нет распознавания; нет бара → край архива;
  промежуток ленты перед баром → непрерывность потеряна; бар накрыл `b` →
  контакт; бар целиком за `b` → переход без касания; иначе бар оценивается.
- `q_event = t0 + k` для первого бара k ≤ 50 с пробоем, пока сцена жива. Один
  `q_event` на фильм.
- Окно +50 — только для обнаружения. Без события к +50 — `window_censored_50`.
  Он, как и выходы до события (контакт, переход без касания, промежуток ленты,
  край архива), публикуется в переписи и в популяцию не входит.
- Популяция: жив, лента непрерывна, контакта и перехода без касания на
  `(t0, q_event]` нет; отсюда `d > 0`.
- Оговорка оператора — часть результата: примерно у 10 % средних и поздних
  распознаваний есть подмена референта. Эти случаи не исправляются и не
  исключаются.

## 3. Геометрия

`c = close(q_event)`, `b = exit_boundary`, `d = |c − b| > 0`, `m = 2c − b`.
Зеркало фиксируется один раз и не двигается. Равное расстояние не предполагает
равных вероятностей.

## 4. Автомат после `q_event`

Бары `q_event + 1, …` без горизонта, на каждом по порядку:

1. бара нет → `archive_edge`;
2. промежуток ленты перед баром → `lost_observability`;
3. бар накрыл `b` и `m` → `same_bar`;
4. накрыл только `b` → `own_first`;
5. накрыл только `m` → `mirror_first`;
6. бар целиком за `b` или за `m` без касания → `gap_transition`, записывается,
   через какой уровень;
7. иначе следующий бар.

Касание — `low ≤ уровень ≤ high`, одно для обоих уровней. Каждый терминал
окончательный. Реализация — `race084.py`, режим full.

## 5. Направление

- `B = P(own_first) − P(mirror_first)`, знаменатель `N` — вся популяция
  `q_event` территории.
- **`gap_transition`** — отдельный наблюдаемый терминальный переход сцены: входит
  в `N`, не входит ни в `own_first`, ни в `mirror_first`. Это не контакт, не
  неизвестный победитель и не own или mirror. Доля и уровень, через который шёл
  переход, публикуются отдельно.
- **Неопределённость идентификации:**
  `U_id = same_bar + lost_observability + archive_edge`,
  `B_lo = (O − M − U_id)/N`, `B_hi = (O − M + U_id)/N`. Conservative outer bound;
  публикуется по причинам. Может быть шире истинного множества; solver не строится.
- **Статистика:** блочный бутстрэп по `t0_day` (UTC), блоки 1 / 5 / 20 подряд
  идущих дней из дней популяции, 2 000 реплик на длину, seed 20260916 + длина
  блока. Для каждой длины — [2,5 % от `B_lo*`; 97,5 % от `B_hi*`]; публикуется
  самое широкое.
- **Вердикт по NQ evaluation:**
  - всё множество выше нуля — own первой достигается чаще, асимметрия
    установлена;
  - ниже нуля — чаще mirror;
  - иначе unresolved с числом: вне множества значения исключены. Причина —
    идентификация, если `[B_lo; B_hi]` содержит 0, или точность, если не
    содержит.
  - Класс «достаточно точное отрицательное ограничение» не присваивается.
- **Отрицательный или нерешённый результат закрывает только этот замороженный
  контраст с якорем на событии, а не RIZ вообще.**

## 6. Скорость, отдельно от направления

Для `h = 5, 15, 60` баров после `q_event`:

- `R_h` лежит в [достижения ≤ h; достижения ≤ h + (`lost_observability` +
  `archive_edge`) ≤ h] / N, где достижение — `own_first`, `mirror_first` или
  `same_bar`;
- категории на `h`: own / mirror / `same_bar` / `gap_transition` / unknown
  (`lost`, `edge`) / neither;
- `gap_transition` ≤ h публикуется отдельно и в `R_h` не входит.

Скорость в вердикт не входит, `B` скоростью не читается.

## 7. Отчёт рядом, не вход в вердикт

- Те же `[B_lo; B_hi]` и множество §5 по north и south; у фильмов, чей `q_event`
  лежит в окне 03:00 ET → закрытие XNYS (`setups/S-04/calendar.parquet`,
  `base/081/trading.py`); с весом пути (§1).
- **Бенчмарк `q = 5`** — описательный фиксированных часов. Популяция: жив, лента
  непрерывна, перехода без касания нет на `(t0, t0+5]`. Тот же автомат, границы,
  бутстрэп, скорость и территории. Формальной разности нет. Разница долей или
  скорости между `q = 5` и `close_break` эффектом якоря не читается: популяции
  разные.
- Перенос ES и YM: у каждого инструмента свой класс по правилу §5 и отношение к
  NQ evaluation — совпадает, противоречит или не решён. Перенос NQ evaluation не
  спасает и не отменяет.
