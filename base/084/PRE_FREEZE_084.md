## 2. Событие и `q_event`

Оператор — ровно EVENT_XRAY_MAP §2, `close_break`.

- Наружу — от собственной границы `b` (north вверх, south вниз); `H`, `L`, `C` —
  внешний экстремум, внутренний экстремум и закрытие бара в этих координатах.
- `M` — бегущий внешний экстремум, начиная с `H[T0]`. Бар **обновляет**, только
  если `H > M` строго. **Ничья** `H = M` — не обновление и `P` не сдвигает. `P` —
  первый бар, достигший текущего `M`.
- **Пробой закрытием:** бар без обновления и `C < L[P]` строго. Закрытие, равное
  `L[P]`, пробоем не является. Бар с обновлением пробоем не бывает.
- **Порядок на баре +k:** k > 50 → распознавания нет; нет бара → край архива;
  промежуток ленты перед баром → непрерывность потеряна; бар накрыл `b` → контакт,
  Film-1 кончился; бар целиком за `b` → переход без касания; иначе бар
  оценивается.
- **`q_event` = t0 + k** для первого бара k ≤ 50 с пробоем, пока сцена жива. Один
  `q_event` на фильм, распознаётся на закрытии бара.
- **Окно +50 — только для обнаружения.** Фильм без события к +50 —
  `window_censored_50`, в популяцию гонки не входит, публикуется в переписи. На
  гонку после `q_event` окно не переносится.
- **Выходы до события** (контакт, переход без касания, промежуток ленты, край
  архива) публикуются по причинам и в популяцию не входят.
- **Популяция `q_event`:** жив, лента непрерывна, контакта и перехода без касания
  на `(t0, q_event]` нет. Значит `close(q_event)` строго на стороне выхода и `d > 0`.
- **Оговорка оператора, часть определения результата.** Примерно у 10 % средних
  и поздних распознаваний есть подмена референта. Эти случаи не исправляются и не
  исключаются.

## 3. Геометрия

`c = close(q_event)`, `b = exit_boundary`, `d = |c − b| > 0`, `m = 2c − b`.
Зеркало фиксируется один раз, лежит на тиковой сетке, не двигается. Равное
расстояние не предполагает равных вероятностей.

## 4. Автомат после `q_event`

Бары `j = q_event + 1, …` без горизонта. На каждом баре по порядку:

1. бара нет → `archive_edge`;
2. промежуток ленты перед баром → `lost_observability`;
3. бар накрыл `b` и `m` → `same_bar`;
4. накрыл только `b` → `own_first`;
5. накрыл только `m` → `mirror_first`;
6. бар целиком за `b` или целиком за `m` без касания → `gap_transition`, сторона
   записывается;
7. иначе следующий бар.

Предикат касания для обоих уровней один: `low ≤ уровень ≤ high`. Каждый
терминал окончательный. `gap_transition` — **наблюдаемый терминальный переход
сцены**: геометрия own-vs-mirror перестала быть той же сценой до канонического
контакта. Это отдельная категория, а не разновидность неизвестного порядка.
Поздний контакт после неё победителя не назначает.

## 5. Направление — один пункт открыт

- `B = P(own_first) − P(mirror_first)` на всей популяции `q_event` территории;
  первичный вес — `riz_id`.
- **Неопределённость идентификации — фиксировано.** В неё входят состояния, где
  направленный порядок действительно неизвестен: `same_bar`,
  `lost_observability`, `archive_edge`. `U_id = same_bar + lost + edge`,
  `B_lo = (O − M − U_id)/N`, `B_hi = (O − M + U_id)/N`. Это conservative outer
  bound, публикуется по причинам. Он может быть шире истинного множества: у
  фильмов на общем скрытом участке не все сочетания исходов совместимы. Solver не
  строится.
- **Открыто: роль `gap_transition` в `B`.** Он **не** кладётся автоматически в ±1
  внешней границы и остаётся отдельной терминальной категорией со своей долей и
  стороной. Предложение: `gap_transition` остаётся в знаменателе `N` и не входит
  ни в `P(own_first)`, ни в `P(mirror_first)` — третий наблюдаемый исход, не
  неизвестный порядок. Масштаб — §9. Семантика не зависит от величины доли.
- **Статистика — фиксировано:** блочный бутстрэп по `t0_day` (UTC), блоки 1 / 5 /
  20 подряд идущих дней, 2 000 реплик на длину блока, seed 20260916. Для каждой
  длины — [2,5 % от `B_lo*`; 97,5 % от `B_hi*`]; публикуется самое широкое.
- **Вердикт по NQ evaluation — фиксировано:**
  - всё множество выше нуля — установлен перевес own;
  - ниже нуля — установлен перевес mirror;
  - иначе unresolved с числом: вне множества значения исключены. Причина —
    идентификация, если `[B_lo; B_hi]` сам содержит 0 (разложение `U_id`), или
    точность, если не содержит.
  - Класс «достаточно точное отрицательное ограничение» не присваивается: порога
    величины в спецификации нет.

## 6. Скорость — отдельно от направления

- `τ` — бары от `q_event` до первого бара, накрывшего `b` или `m`. `own_first`,
  `mirror_first` и `same_bar` — достижение уровня.
- `R_h` для `h = 5, 15, 60`: нижняя граница — достижения не позже `h`; верхняя
  добавляет `lost_observability` и `archive_edge` не позже `h`. `gap_transition`
  не позже `h` — отдельная категория; его место в `R_h` следует решению §5.
- На каждом `h`: own / mirror / `same_bar` / neither / `gap_transition` / unknown
  (`lost`, `edge`), причины сохраняются.
- В `B` скорость не входит, `B` скоростью не читается.

## 7. σ — пункт открыт, предлагается отложить

Разделение `B` и скорости **не** отвечает на родительский вопрос H1/H2 о σ.
Предлагаемый статус для этого цикла:

**σ / H1 / H2 are deferred parent-layer questions and are not answered or closed
by this cycle.**

Основание. 084 заменил произвольный `q = 5` на наблюдаемый `q_event` для общего
`B`. Перенос σ на `q_event` не наследуется из 082 без новых решений:

- `prefix_sigma = mean(high − low)` по `T0 … q_event` имеет длину окна от 2 до 51
  бара и привязана ко времени распознавания. Сравнение половин σ смешивает σ со
  временем распознавания и составом часов.
- Ключ страты для σ (082: `d | side | TF` против геометрии `d | side`) не был
  решён, а его реализуемость на NQ evaluation в `q_event` до финального freeze
  проверить нельзя.

Если архитектор оставляет σ в текущем решающем цикле, до направленных исходов
нужно заморозить: окно σ в `q_event`, контраст (медиана внутри страты),
ключ страты, `MIN_SIDE`, веса, отклики `ΔB` и `ΔR_h` с границами по §5 и правило
вердикта H1/H2.

## 8. Зависимость, неоднородность, бенчмарк, перенос

- Зависимость — только блоками дней.
- Отчёт, не вход в вердикт: `B` north / south; `B` у фильмов с `q_event` в окне
  03:00 ET → закрытие XNYS (календарь `setups/S-04`).
- **`q = 5` — описательный бенчмарк фиксированных часов.** Популяция: жив, лента
  непрерывна, перехода без касания нет на `(t0, t0+5]`. Тот же прибор, те же
  территории, публикуется рядом. Формальной разности нет. Разница скорости или
  долей исходов между `q = 5` и `close_break` эффектом якоря **не** читается:
  популяции разные.
- Перенос ES и YM: тот же оператор (порядковый, без тиковых параметров), окно,
  популяция, автомат, границы, бутстрэп, скорость. Результат по инструменту:
  совпадает, противоречит или не решён; NQ evaluation им не спасается и не
  отменяется.
