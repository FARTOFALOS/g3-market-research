## 2. Замороженная execution-интерпретация (одна, до результата)

- **signal/recognition** = завершённый `close_break` на закрытом баре `q_event`.
- **entry** = самая ранняя защитимая исполнимая цена после распознавания:
  `E = open(q_event + 1)`. `close(q_event)` не кредитуется (распознавание
  завершается на этом закрытии; вход туда — hindsight).
  - если `q_event+1 > last` или лента прервана (`kind[q_event+1] != 0`) — исполнение
    недоступно → **execution_unavailable (unknown)**.
- **continuation-side target** = `a` (замороженная граница за `M`).
- **opposite boundary (stop)** = собственная `b` сцены.
- **direction** `dir = +1` north / `−1` south (в сторону продолжения).
- **исход исполнимой сделки** (автомат `_fork` с бара `q_event+1`, exit по уровню):
  - `a` первой (CANCEL или gap_through_a) → **target-first**, exit `= a`;
  - `b` первой (WIN или gap_through_b) → **boundary-first**, exit `= b`;
  - same_bar → **unknown** (внутрибарный порядок не восстановим из минутного OHLC);
  - lost_observability / archive_edge → **unknown** (censored).
- **missed opportunity**: если благоприятная граница достигнута до исполнимого входа —
  `dir·(E − a) ≥ 0` (открытие уже за целью) → **missed**, не profit.
- **adverse gap at entry**: если `dir·(E − b) ≤ 0` (открытие уже за стопом adverse) →
  отдельный бакет **adverse_gap_entry** (реализованный net = −cost), не сворачивается
  в положительный P&L.
- **P&L в пунктах**: `gross_E = dir·(exit − E)`; `net_E = gross_E − cost`
  (cost = 1.00 NQ). Reference от 086: `gross_c = dir·(exit − c)`; loss распознавание→вход
  `give_up = gross_c − gross_E = dir·(E − c)`.
- Никаких альтернативных входов, стопов, целей, задержек, фильтров, порогов и
  уточнений состояния.
