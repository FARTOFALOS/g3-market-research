# Песочница RIZ — состояние работы

Интерактивный стенд: свечи задаются руками, машина RIZ считает по ним состояние
зон. Нужен, чтобы синхронизировать понимание семантики RIZ без обращения к
рынку — и чтобы новый агент, входящий в проект, понимал, что означают синие
зоны, до того как строить исследовательские абстракции.

Опубликован как артефакт: **https://claude.ai/code/artifact/885ca0c9-5922-4e00-bcac-15df2a17f97a**

Ничего из этого каталога не является частью поля G3. `pytest`, `g3-riz` и все
исследовательские запросы работают при полностью отсутствующем `design/`.

## Файлы

| Файл | Что это |
|---|---|
| `Main.dc.html` | Артборд песочницы: график, редактор свечей, лестница событий. Здесь же JS-порт машины. |
| `Semantics.dc.html` | Артборд-справка: что такое синяя зона, лестница состояний, четыре времени, что синим не является. |
| `canvas.json` | Раскладка холста и заметка-подсказка. |
| `riz-sandbox.html` | Собранная страница. **Генерируется**, руками не править. |
| `tools/riz_machine.py` | Независимый Python-порт машины. Эталон для сверки. |
| `tools/dump_presets.mjs` | Вытаскивает пресеты из артборда и гоняет их его же машиной. |
| `tools/verify_presets.py` | Сверяет два порта между собой. |
| `tools/presets.json` | Результат `dump_presets.mjs`. Генерируется. |
| `tools/tv_bars_window.mjs` | Тянет реальные OHLC из работающего TradingView через CDP. |
| `scenarios/raw/*.json` | Сырые ленты, из которых собраны реальные пресеты. |

## Как пересобрать и обновить

Правится **только** `Main.dc.html` / `Semantics.dc.html` / `canvas.json`.
Дальше пересборка и публикация по той же ссылке:

```bash
node "<каталог скилла design>/seed-canvas.mjs" --template "<каталог скилла design>/payload.template.html" --out riz-sandbox.html --title "Песочница RIZ" --artboard Main.dc.html --artboard Semantics.dc.html --canvas canvas.json
```

Каталог скилла выдаёт `/design` при вызове. Затем `--check riz-sandbox.html`,
затем публикация артефакта тем же `file_path`, с `contract: "0.1.31"` и тем же
favicon; `capabilities` на повторной публикации не передавать.

## Проверка после любой правки

```bash
node tools/dump_presets.mjs > tools/presets.json
python tools/verify_presets.py
```

Артборд считает своей копией машины, `riz_machine.py` — отдельным портом с того
же Pine. Расхождение означает, что одна из копий уехала. На момент последней
сборки все 11 пресетов совпадают.

Отдельно быстрый прогон эталона: `python tools/riz_machine.py` — проверяет, что
на реальной ленте NQ 11м получается ровно одна синяя зона 29625.00 / 29617.25.

## Пресеты и что каждый доказывает

| Ключ | Что показывает |
|---|---|
| `real` | Реальный синий 2X, NQ1! 11м, 28 августа. Совпадает с боксом на графике. |
| `wick` | Реальная зона NQ 5м, умершая за один бар: телу не хватило 2.25 пункта до юга. |
| `whatif` | Тот же тейп с поднятым Low бара 18:25 — зона уходит в брейкер `sbk` и живёт до 01:15. |
| `blank` | Чистый лист под свои ситуации. |
| `a` | Один span это не 2X. |
| `b` | Повтор раньше `cr+2` не удваивает, а убивает зону через ветку теней. |
| `brk1` | Брейкер `sbk2`: обе стороны живы, тень снимает север, тело закрывается под югом. |
| `brk2` | Брейкер `sbk`: сторона снята заранее, условий на хай нет. |
| `brk3` | Брейкер `nbk2`, зеркальный, магнит сверху. |
| `d` | `nx=2` при снятой границе — синего не будет никогда. |
| `e` | 3X это тот же объект, а не новая зона. |

Кнопка «Случайные» генерит случайное блуждание для поиска новых ситуаций.

## Что установлено и перепроверять не нужно

- **`RIZ BLUE v1.0` и `RIZ v9.7` содержат одну и ту же машину.** Тела
  `f_machine()` без комментариев совпадают: 167 строк, одинаковый SHA-256.
  Отдельной «логики v1.0» не существует. Ветки `sbk2`/`nbk2` появились в v8.6 и
  с тех пор не менялись.
- **Порт в песочнице полный**, включая блок экспорта: чекбокс «живой» включает
  предварительное гашение сторон (`nAp`/`sAp`), пересчёт брейкера и
  `is2xPreview` по незакрытому бару. Этот слой только отображение, состояние
  машины он не меняет.
- **T0 и нативное подтверждение — разные события.** На зоне 29625.00 / 29617.25
  T0 наступил в 11:51 (первая минута, на которой развивающееся тело 11-минутного
  бара прошило зону во второй раз), а `nx` ушёл на 2 только на закрытии в 11:58.
  Между 11:51 и 11:58 предикат гас и зажигался снова — в 11:54 закрытие
  вернулось внутрь зоны. Время везде нью-йоркское.
- **Уровень может пережить объект.** BISI 29480.00 / 29471.00 умер 18:25 в
  воскресенье, но через два бара родился SIBI 29480.00 / 29476.50 с тем же
  верхом, и уже его север дожил до 04:40. Машина эти объекты никак не связывает:
  преемственность уровня между зонами — вычисляемое чтение поверх поля, а не
  недостающий факт. Правило, по которому уровень влиял бы на решения машины,
  потребовало бы изменения замороженной семантики и отдельной санкции оператора.

## Незакрытое

- Страница ни разу не проверена глазами в отрисованном виде — сборка и оба
  порта проверены, вёрстка нет. Доступный браузер не залогинен в claude.ai,
  локальный файл открыть не дал.
- Блок «Сценарий текстом» был и удалён по просьбе оператора. Обмена сценариями
  через чат сейчас нет; при необходимости вернуть отдельной строкой.
- Пресет `whatif` содержит один артефакт склейки: зона, рождённая в 02:10,
  получается 29485.25 / 29472.25 вместо реальной 29485.25 / 29468.00 — у неё
  сместился C1 из-за вырезанного куска. На разбираемые зоны не влияет.
